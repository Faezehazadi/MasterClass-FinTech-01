# Session 2

## 1. Give Me Some Credit

`1.give_me_some_credit/give_me_some_credit.ipynb` explores the Give Me Some Credit dataset and prepares features for credit-risk analysis. It inspects the `SeriousDlqin` target, checks duplicates and invalid values, removes a target-leaking feature, and creates a stratified train/test split. It then handles missing values using training-set medians, investigates outliers and relationships with the target, and engineers features that summarize past-due payments. Finally, it explores age and debt-ratio bins, calculates weight of evidence (WOE) and information value (IV) for age groups, and examines feature redundancy and mutual information.
